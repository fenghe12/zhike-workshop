# DiTalker最后输出层零初始化修正

[English](README.md) | 简体中文

用户明确的设定为新增残差分支最后输出层置零。此前将全部新增参数置零属于实现理解错误，旧实验保留为历史对照。

本次使用50个真实HDTF case、100次AdamW更新、batch1、512×512，冻结完整EasyAnimateV3基础模型，训练全部11组新增部件。遮罩未知区域使用原流程的−1。重新加载基础权重，未恢复错误全零实验的新增参数。

共85层出口为零：28层ACA、28层SCA、28层ECA出口投影，以及PoseGuider出口卷积。内部投影、查询向量和LayerNorm缩放保留正常初始化。比例门控初值为tanh(1)，其最后线性层权重为0、偏置为1。REPA是辅助损失投影，保留正常初始化。

检查逐组首次非零梯度步骤、100步内非零梯度次数、逐张量覆盖，以及与初始化参数的实际差异。出口为零时，内部参数首步零梯度可能符合预期，不能据此单独判断失败。每组必须同时获得非零梯度并发生参数更新。冻结基础参数不能获得梯度，抽样值必须保持一致。

恢复目录、私有条件、检查点计划、持久化运行环境和顺序命令见英文说明。完整检查点与权重直接保存至私有OBS，随后完整读取并检查优化器计数及所有新增参数。公开代码不包含模型、原片、密钥、签名地址或云资源启停控制。

本次还执行相同50例固定噪声的训练前后对照，以及两个训练case的3次推理：第一例CFG1和CFG7，第二例CFG1。第一例沿用原诊断报告人物。所有输出为512×512、16帧、6.25FPS、25步、seed42。随后使用完整预训练LPIPS、SSIM和PSNR进行单例诊断，不作为泛化或收敛结论。

完成后finish_repair.py生成本地视频与结果片段，operator-audit会话的integrate_reports.py将原DiTalker和CogPortrait各100条loss、曲线、历史报告、诊断与本次修复结果整合到同一个离线HTML。旧全参数为零实验与本次正确初始化明确区分。CogPortrait代理规划与KTO仍不在本次修复范围内。

## 实际结果

本次单张Ascend910B2完成50例、100步。11/11组均获得非零有限梯度并实际更新，908/908个新增参数张量曾获得非零梯度。注意力出口、姿态与REPA从第1步获得梯度；ScaleAdapter、音频投影和风格内部模块从第2步开始，其非零梯度次数为99/100。完整私有检查点已重新读取，所有新增权重和优化器计数核对通过。

50例固定噪声纯去噪MSE由0.041943734变为0.042036540，略升0.221%。零梯度问题已解决，100步短程训练尚不能证明质量提升或收敛。两例共3次真实推理均为512×512、16帧，逐帧人脸检出均为16/16，具体PSNR、SSIM与LPIPS见英文表格。
