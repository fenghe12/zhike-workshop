# 课程工作台操作与资源控制

2026-10-27 更新。

## 手机输入与恢复

手机端使用 1 MiB 分段上传。上传编号和已收到的分段保存在服务端持久化目录中，同一账号重新提交同一文件时只发送缺失部分。文件完成后仍执行文档结构、图片和音频格式检查。未完成分段保留七天。

课程表单和选定文件通过 IndexedDB 保存在当前浏览器，按账号编号区分。刷新后恢复草稿，人物和声音使用授权保持未勾选。退出账号会清除该账号在当前浏览器中的草稿。浏览器空间不足或不支持文件保存时，页面明确提示保持打开。

重新执行会清除起始步骤和后续步骤的旧进度、时间及当前结果记录。前置步骤保持完成，最近十次旧输出引用保存在执行历史中。相同任务已排队或执行时拒绝重复提交。

数字人原始视频、照片版本和对应音频全部匹配时，即使模型计算已经停止，也可继续整理缓存视频并进行 CPU 合成。缓存不匹配时仍需恢复模型计算。

## 账号

设置页面支持修改密码。成功修改会注销旧会话，并为当前浏览器生成新会话。

邮箱验证、注册邮箱验证和忘记密码共用一次性六位邮件验证码，有效期十分钟，错误尝试最多五次。启用 SMTP 后，新注册账号必须验证邮箱；旧账号可在设置中验证邮箱。只有已验证邮箱可用于密码找回。

发信依赖真实可用的 SMTP 配置。配置项见 `.env.example`，密码通过私密持久化文件读取，服务支持 TLS 或 STARTTLS。没有配置发信服务时，页面显示不可用，不能将本地发信器测试描述为真实邮件投递成功。用户协议和联系人由现有配置提供。

## 素材删除与期限

默认永久保留。用户可选择 7、30 或 90 天，到期清理已结束课程及未被课程引用的上传素材。执行中的课程不自动删除。课程删除会删除对应任务目录中的实际文件；仍被课程引用的原始素材不能单独删除。共享演示课程只允许其创建者删除。

本功能管理课程服务器上的任务和素材。历史恢复备份及模型备份单独保留，不向整个 OBS 桶设置删除期限。对 OBS 新建业务前缀配置生命周期时，应限定到该前缀并保留已有规则，不覆盖恢复备份。

## 费用与计算控制

生成前可以估计所选语言的生成时间和计算费用，估计结合已有课程的实际运行记录；环境恢复、存储及流量另计。用户可设置不超过 50 元的单任务计算预算，服务端拒绝估计超出已保存预算的执行请求。

`scripts/compute-controller.py` 在持久化工作站或专用控制器运行。网页服务只保存独立控制令牌，云账号密钥留在控制器。用户通过页面提交启动请求，控制器按配置执行启动、恢复与停止程序。每次启动必须返回平台自动停止时间，并受到累计预算、单次运行期限及空闲期限约束。控制器退出或启动失败时执行停止程序。云服务原生定时停止仍需启用。

私密配置结构如下，所有目录应替换为实际确认的持久化位置：

```json
{
  "runtimeDirectory": "/persistent/smartcourse/controller",
  "controlTokenFile": "/persistent/smartcourse/private/control-token",
  "apiBase": "http://127.0.0.1:18771",
  "computeOwner": "configured-project-owner",
  "totalBudgetCny": 50,
  "hourlyCeilingCny": 25,
  "maximumSessionSeconds": 3600,
  "idleSeconds": 300,
  "startCommand": ["python3", "/persistent/smartcourse/operator/start-course-session.py"],
  "stopCommand": ["python3", "/persistent/smartcourse/operator/stop-course-session.py"]
}
```

启动程序负责检查挂载、恢复必要文件、启动模型服务并返回 `{"computeState": {...}}`。停止程序使用云端停止接口并检查资源归属。控制器未运行时，页面禁止提交启动请求并提示联系管理员。控制器不会默认创建新资源，也不会把云账号密钥写入网页。

发布计算就绪状态前，用 `scripts/check-media-runtime.py` 分别检查语音和数字人环境。语音 overlay 固定使用 `transformers 4.51.3`，数字人使用独立的 `4.57.3` overlay，不能共用同一个依赖目录。恢复生产环境时，应包含原 `npu-base` 与 `cosyvoice-py311` 的全部依赖，不能以只验证过声音转换的精简环境替代。依赖版本分别记录在 `recovery/requirements-cosyvoice-overlay.txt` 和 `recovery/requirements-flashhead-overlay.txt`。

网页停止和模型计算停止分别管理。普通按需 ECS 关机后仍需保留磁盘和 OBS 的费用；测试结束后应检查云端状态。Notebook 不再使用时，应在同步代码和新输出、确认可恢复后删除实例及关联托管磁盘。
